# 随身读 · 高性价比人生指南

把开源书《高性价比人生指南》做成手机上读的网站。打开就是目录，记得上次读到哪，断网也能读全书。读者做的非官方页面。

线上地址：https://www.heigeai.com/live/

![随身读的三个页面：目录、一条建议、夜间模式](docs/screenshot.jpg)

这是黑哥想做的系列网站里的一个，代码完全开源。这一个是液态玻璃风格：内容都装在厚玻璃里，彩光从底边透出来，颜色跟着每条建议换回的东西走。

原生 HTML、CSS、JS，不依赖任何 npm 包，构建出来全是静态文件。

## 有哪些页面

- **目录（打开就是这一页）**：按处境进（刚被裁、刚怀孕、家里有老人……），按换回什么筛（寿命、钱、时间精力、人身自由），下面是 34 节。读过的人顶上多一行「接着读」，点一下回到上次那条；原书改了你读过的条目，「接着读」下面会多一行「读过的改了」。目录底下还有随手翻一条、先看性价比最高的条目、原书最近的改动。
- **阅读**：每条按「花掉 / 换回 / 证据」排，下面是说人话和备注，成本、收益原文、来源收在折叠里。可以收藏、标记做到了、分享，能调字号、开夜间模式。正文里的「见第 X 节第 Y 条」能点过去，术语（HR、RR 等）点一下有解释。
- **搜索**：全书搜索，可以叠加证据 A、不花钱、不费毅力、性价比极高、四类换回这些标签。
- **读过的改了**：原书改了你读过的条目会提醒，写明改的是哪一栏；也列出最近新增的条目。
- **急救**：六种常见情况的第一步；按压引导页有每秒 2 次的节拍球和节拍声，打开时手机不熄屏。
- **我的**：阅读进度、收藏、做到了；全书离线缓存状态；加到主屏幕的办法；把进度发给自己（不用账号，生成一个链接）；夜间模式、字号、简化特效。

## 构建

需要 Node 18 以上和 git，不需要 `npm install`。

```bash
node scripts/build.mjs          # 第一次会自动把原书稿浅克隆到 .book/
node scripts/build.mjs --sync   # 先把书稿更新到原仓库最新，再构建
```

产物在 `dist/`，全是静态文件。

## 第一次打开为什么快

服务器在海外，国内手机每多一次来回都要等。所以：

- 样式、脚本和画目录要的那一小份数据（各节标题、条数、口径、统计、处境、急救），构建时直接写进 `index.html`。第一次打开只等这一个文件（压缩后约 35 KB），不用等它下完再去要样式和脚本、脚本跑起来再去要数据。
- 每条的标题和术语表在 `data/meta.json`，目录画完再在后台取；点开一节时和那一节的正文一起等。
- 每节拆成两份：`data/ch/` 是摊开就能看到的（标题、花掉换回、说人话、备注），`data/foot/` 是折起来的「成本 · 收益原文 · 来源」，后者占整节的三分之二。点开一节先只取前一份（第 1 节压缩后约 24 KB，原来要 72 KB），后一份紧接着补上。
- `meta.json` 和更新记录取完就装离线缓存，安装时只存页面和两份小数据，图标不进缓存。随后补存各节：同时最多取 2 个，顺序是急救那一节、各节正文、各节折起来的部分、搜索索引；用户自己点开的内容在取的时候，补存先停下让路。连接一直在用，服务器不会因为空闲把发送速度降回起步值。
- 换上新版本以后，正文按新版本重新存一遍（没改的文件服务器只回「没变」）；存齐之前断网，先用旧版本存的顶着，存齐了再删旧的。

2026-11-05 在本机（走代理）用没有缓存的无头 Chrome 交替打开新旧两版各 6 次，中位数：出内容 5.71 秒 → 5.06 秒；出内容 1.5 秒后点开第 1 节 575 → 489 毫秒，旧版有两次卡到 2.3 秒和 3.4 秒；15 秒时存好的节数 15 → 34。剩下的大头是连上服务器本身（测试那台电脑上约 4.4 秒），和页面无关。

## 本地预览

```bash
python3 -m http.server 5173 --directory dist
```

然后打开 http://localhost:5173 。离线缓存只在 http(s) 下生效，直接双击 `index.html` 打不开。

## 部署

`dist/` 全是静态文件，传到任意 HTTPS 静态托管都能用，放在子路径下也行。读者在国内的话，GitHub Pages、Cloudflare Pages 这类海外托管打开不稳定。

用自己的服务器：

```bash
cp .deploy.env.example .deploy.env   # 写上服务器、目录和网址，这个文件不进仓库
node scripts/build.mjs --sync        # 书稿更新到最新，再构建
scripts/deploy.sh                    # 上传到服务器，再从公网核对版本和关键文件
```

- nginx 配置只配一次，例子在 `scripts/nginx-example.conf`。
- 每次上传前，服务器上的上一版会先存到同一层的隐藏目录，出问题可以换回去。
- 装过的用户下次打开会在「我的」里看到「有新内容」，点一下换上；读到一半不会被强制刷新。

## 想拿去做别的内容

页面框架和离线缓存不挑内容，和这本书绑定的地方有这几处：

- `scripts/build.mjs`：`REPO` 是书稿仓库地址，`parseChapter` 这几个函数按这本书的 Markdown 格式解析，换内容主要改这里。
- `src/content.json`：处境入口、急救入口、按压步骤，都是给这本书手写的。
- `src/app.js`：「急救」「按压引导」两页和开头 `KOU` 那几张表，是这本书特有的。
- `src/styles.css`：玻璃质感和动效都在这里，换风格改这个文件。
- `src/index.html`、`src/manifest.json`、`src/icons/`：标题、描述和图标。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `scripts/build.mjs` | 构建：解析书稿、生成数据、把样式和脚本写进页面、打包到 `dist/` |
| `scripts/deploy.sh`、`scripts/nginx-example.conf`、`.deploy.env.example` | 发布到自己的服务器，和 nginx 配置的例子 |
| `scripts/make-icons.mjs`、`scripts/icon.html` | 生成应用图标（一般不用再跑） |
| `src/index.html`、`src/styles.css`、`src/app.js` | 页面模板、样式（玻璃质感和动效都在这里）、全部页面逻辑；构建时样式和脚本会被写进页面模板 |
| `src/sw.js` | 离线缓存 |
| `src/content.json` | 编辑精选：处境入口、急救入口、按压步骤；`hooks` 是以前首页的摘句，现在不显示，留着备用 |
| `src/manifest.json`、`src/icons/` | 装到桌面用的应用信息和图标 |
| `.book/` | 原书稿（浅克隆，不提交） |
| `dist/` | 构建产物（不提交） |
| `docs/` | README 用的截图 |
